# Trade Document Format Converter

A Python utility for converting and standardizing international trade document formats between different country requirements.

## Features

- Convert between CO formats (China, US, EU, ASEAN)
- Batch processing for bulk document conversion
- Validation against country-specific requirements
- Export to PDF, DOCX, and XML formats

## Usage

```bash
python3 convert.py --input document.xml --output-format pdf --country china
```
